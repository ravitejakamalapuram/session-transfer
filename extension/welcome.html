Session Transfer is installed

Move a logged-in session from one browser to another.

How a transfer works

  1. 1
    In the source browser: Transfer Session Open the site where you are logged in, click the Session Transfer icon and choose Transfer Session. Copy or download the package it makes and note the transfer code if one is shown.
  2. 2
    In the destination browser: Receive Session Install Session Transfer there too, click its icon and choose Receive Session. Paste the package or open the file.
  3. 3
    Enter the transfer code Packages are encrypted by default: type the code shown in the source browser, and send it on a different channel from the package. If you ticked Skip the code (same computer only) there is no code and the package alone is enough, so treat it like a password.
⚠ A package expires 5 minutes after you make it. If it runs out, make a new one with Transfer Session.

Pin the toolbar icon

Click the puzzle-piece Extensions button in the Chrome toolbar, then the pin next to Session Transfer. The icon then stays next to the address bar, one click away in both browsers.
